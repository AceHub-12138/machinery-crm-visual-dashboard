## 超宽布局

- 默认保持 1920×1080；新增模式计划为 3840×1080。
- 五列顺序：经营指标、地图、合同与回款、交付预警、交付里程碑。地图仍是最大区域；交付由底条移入右列。
- 初始列宽预算：480 / 1440 / 640 / 600 / 596，间隙 14、四周内缩 14，合计 3840。正式施工时还需按真实内容调整与测量。
- 预览以常规和超宽两种布局供对照；它是布局示意，正式屏幕像素尺寸以施工后的几何测试为准。

## 空闲、氛围和过渡

- 空闲超过 30 秒再聚焦一个面板，每块停留 8 秒；减少动效时关闭。预览中的“空闲聚焦”只展示高亮外观。
- 底座光环与轨道粒子复用现有 Canvas 循环，不增加 RAF；保持原 8ms CPU 门限。预览仅展示光环位置，尚未验证正式粒子性能。
- 进入语音时，底屏先用 300ms 压暗；标准模式叠加 blur(6px)，低配仅压暗。退出保留折回核心的方向。
- 预览的调整面板可切换语音覆盖层、低配、减少动效、空闲聚焦和光环；不触发真实语音流程。
