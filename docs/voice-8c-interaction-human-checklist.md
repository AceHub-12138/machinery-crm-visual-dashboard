# 小川交互改版：本机真人检查表

功能施工完成后的真人验收；Step0的5次敏感度对照不能代替这一轮。Mac保持开机，本地大屏：http://localhost:3015/screen/sales?voiceLive=1 。已打开的大屏带原有鉴权；不要复制或公开令牌。

先确认输入／输出设备与音量，记录麦克风位置、与音箱距离。当前KZ耳机麦克风在Mac旁、本人前方，距离未测，属于非展厅摆位。展厅仍需桌面或USB麦克风、实际音箱及0.5–1米摆位复测。

1. 点击大屏一次启用声音；若弹出麦克风权限，允许本机收音。按F9或说“你好，小川”，提示播放期间即可问“本月销售怎么样”。应停止提示并回答问题；不丢句首。
2. 在普通答案播放中问“本月目标完成率是多少”。应先让声，约半秒后暂停；问题说完开始新答案，保留旧卡直到问题被接受。重复5次，逐次记录成功／失败及漏字。
3. 答案播放中短咳嗽或发出约0.2秒声音。应恢复原音量、继续原句；不能算一次新问题、不能播“未听清”。
4. 答案刚播完1秒，以及播完后的第3–7秒，分别提出下一问题。每次都应直接接问答；不会先插播“还有其他问题”。在播完前约0.2秒开始一句问题，确认跨越最后样本也不丢句首。
5. 答案播完后保持安静。应先看到8秒聆听环，结束才播追问；提示播放时没有递减环。提示播完后5秒短环，继续安静则温暖退出，返回大屏基线。
6. 在追问提示、温暖退出提示中提出问题，应能打断并继续。主动说“没有了，谢谢”后的告别，以及服务降级话术，保持不可打断。
7. 在已暂停、尚未识别完成时按Esc，立即结束；再次F9／唤醒词应成功。连续做几轮，记录曾出现的间歇性唤醒漏检是否仍存在。
8. 若开了第二个标签，只有发起唤醒的标签收音／播音；关闭其他标签不影响它。关闭所属标签，应取消会话；重新打开后使用新会话。

记录每项是否通过、听到的错误话术／漏字、测试时刻、设备与音量、是否同时运行其他重负载应用。暂不将模拟录音与自动化通过等同真人通过。本机数据使用现有公开fixture，测试交互正确性；不是生产业务数据验收。

性能证据：单页10次末音→新首音P95为1.450秒；与浏览器回归并行的一组P95为1.618秒，未达1.5秒门槛。失败记录保留，负载下的尾部延迟仍须复核。
