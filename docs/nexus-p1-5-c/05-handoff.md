3. 在目标展厅电脑/浏览器/LED 的真实输出分辨率、DPR、刷新率与 GPU 后端上复测，显式确认 60Hz ticker 上限、物理刷新率切换及重校准流程。有效参考低于 52Hz 时暂不具备 Candidate 灰度资格，不能擅自降阈值。
4. 完成目标现场长时运行、隐藏/显示/语音接管/网络刷新/异常数据与恢复验收。单台 Mac、软件后端或有头窗口结果均不能宣布现场合格。
