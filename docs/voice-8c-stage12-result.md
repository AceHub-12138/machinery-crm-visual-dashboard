## 完成内容

1. 增加共享意图枚举、strict JSON Schema 和严格解析；新增非流式 `classify()`，默认 `reasoning_effort=none`。
2. 模型只接收当前问题和意图定义，不接收经营快照或历史答案；分类主路径移除工具轮。
3. 真实分类和 scripted 路由共用确定性卡片构造，播报来自 `card.spoken`，模型文案不进入播报。
4. 新增金额、百分比、计数、负数、日期中文读法；ISO 日期保留年份。按句生成显示原文、读法和 UTF-16 起止偏移，供后续 TTS 消费。
5. 数字备用护栏采用完整 token 比对，异常记录 `numberGuardViolations`；不静默替换整个代码模板。
6. 新增独立 `classifyMs` 指标，对话台显示分类耗时；分类路径的旧流式 `llmFirstToken` 为 null。
7. 修正模板已有口径问题：超额完成率不截成 100%，超额时不再说“还差”；发货提醒使用完整 summary，避免样本数量冒充汇总。
8. 本地模型地址成为默认值，模型 ID 需环境变量显式配置；无 key 时保持 scripted。更新环境样例及服务说明。
