## 同屏与播报的对应关系

| 位置/问题 | 最终数据来源与显示 |
| --- | --- |
| KPI 顶部角标、累计回款环、“回款情况” | `collection.collectionRate`，标签均明确“累计回款率”；不再用本期实收和新合同欠款自行算另一个同名比率 |
| 本期实际完成、“销售情况”、“目标完成率” | `kpis.periodContractAmount`；忽略旧接口目标零值分支的 actualAmount |
| “销售情况” | 同时给本期有效合同额、本期实收 `periodPaidAmount`、本期新合同欠款 `periodUnpaidAmount`；后两项分开显示和播报 |
| 目标未设置 | `targetConfigured=false`，显示“目标未设置”，不显示进度条/完成率环；播报“本月目标尚未设置” |
| 历史零元目标 | configured=true、available=false，显示“目标为 0”，播报目标为零无法计算完成率；不冒充未设置，不开放零目标录入 |
| 区域排名、热力图、区域语音 | 全量 `delivery.regionUnits`；TOP5 + 其他省份 + 地区待确认 = `summary.unitCount` |
| 地图点位 | `routes` 仅作样本，显式说明；地区待确认不落点、不增加省份数 |
| 提醒、交付里程碑、语音发运明细 | 全量总数字段与样本实际条数分别标注“样本 N / 展示总量 M”；到期提醒单位为合同“份” |
| 时间 | 所有时钟/短日期/月份、mock 数据日期窗口显式北京时间，不依赖浏览器及服务器默认时区 |

旧接口没有全量区域字段时，区域卡显示“区域明细待更新”，不从 80 条路线样本求和冒充完整榜单。未知地区保留汇总并单列“地区待确认”。

卡片与话术共用 `buildIntentAnswer` 和确定性 builders；demo 在存在公开 business 字段时也走同一模板。LLM 仍只选意图，模型文本不进入播报。

## 校验与公开投影

本地公开类型同步平台新增标记、regionUnits、unresolvedRegionTotals、reminder totals、routesTotal、milestonesTotal。校验允许负金额、有限负计数，拒绝非有限数及异常金额字符串；全量地区字段齐全时校验区域守恒和省份唯一性。

`fromPublicSalesScreenPayload` 不取网、不读倍率、不再次乘倍率；首屏公开结构使用逐字段白名单（模块配置仅保留已知布尔字段），附加客户名、联系信息、倍率对象不会混入 HTML 数据。mock 仅在服务端按完整种子发货集合生成相同业务字段，不走真实接口适配的聚合路径。

负金额保持原值；相关负计数或负比率的语音请求给确定性的“数据异常，需核对历史数据”卡，保留异常数值，不静默归零或无卡。后续真实数据接入应继续遵守该行为。

## 三项卡片行为及构建

- 发运翻页使用只在播放期间累计的时钟；打断暂停不累计时间，句间空隙保持当前句页，播完停在当前页；最长三页可达。
- 完成率数值与播报保留真实值，图形仅限幅；可见标签超过 999% 显示 `>999%`，合法卡不会被协议上限拒绝。
- 区域条形第一名满格；区域卡说明文字经两种分辨率几何验证。为容纳未知地区与样本说明，仅调整 overlay 区域行与说明间距，保留固定卡片/数据区尺寸。
- 去掉 `next/font/google` 构建期联网请求，使用 PingFang SC / Microsoft YaHei 与 Arial Narrow / Segoe UI 系统字体栈；字体视觉需人工确认，`.screen-*` 基线样式与 `JarvisCore.tsx` 未改。
